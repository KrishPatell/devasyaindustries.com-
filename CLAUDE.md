# CLAUDE.md

## Project Scope

This repository is a self-hosted static export of the Devasya Industries website, originally built in Webflow. It is not a framework app: the production pages are plain HTML files plus a mirrored Webflow asset folder.

The site should render without depending on Webflow's CDN for page assets. Most images, fonts, PDFs, CSS, and Webflow JS live under `cdn.prod.website-files.com/`, and page references are root-relative, for example `/cdn.prod.website-files.com/...`.

There is no `.git` directory in this checkout at the time of writing. Treat it as a working folder unless a repository is initialized or restored elsewhere.

GitHub context found on 2026-06-23: the likely repository is `KrishPatell/devasyaindustries.com-`. This checkout imports that PDF as `documents/chemical-composition.pdf` and wires it through the local generator instead of preserving the typo path. The PR's `.wrapper` centering fix is carried in `styles/devasya-codex.css`.

## Commands

- `npm run serve` starts the local static server at `http://localhost:5173`.
- `PORT=8080 npm run serve` starts it on a different port.
- `npm run check` verifies all local pages and local asset references, including mirrored Webflow assets plus `styles/`, `scripts/`, and `documents/`.
- `npm run check:live` also checks live routes against `https://devasyagroup.webflow.io`.
- `npm run normalize` reapplies shared footer/nav/contact cleanup and the client-change generator across every HTML page.
- `npm run sync` re-downloads page content/assets from Webflow staging and rewrites CDN references to the local mirror.

Important: `npm run sync` can overwrite local HTML page edits. Use it only when intentionally pulling from Webflow, then run `npm run normalize` and `npm run check`. Do not hand-edit generated spec sections in product HTML; update `data/product-specs.json` or `scripts/apply-client-changes.mjs` and re-run `npm run normalize`.

## Local Server Behavior

The static server is `scripts/serve.mjs`. It supports Webflow-style clean URLs:

- `/about` resolves to `about/index.html`.
- `/bars/flats-bar` resolves to `bars/flats-bar/index.html`.
- `/cdn.prod.website-files.com/...` serves mirrored assets.

It also exposes a dev-only dashboard at `/__dev`, listing every discovered page and whether that page has missing local assets.

The server has a raw/decoded URL fallback for asset filenames stored with literal percent encoding. Keep this behavior: several mirrored Webflow files contain names like `%20`, `%2C`, or encoded Unicode.

## Custom Scripts

Two small local scripts are layered on top of Webflow:

- `scripts/current-year.js` replaces every `[data-current-year]` span with the current year.
- `scripts/contact-form.js` controls the contact page enquiry form.
- `scripts/apply-client-changes.mjs` rebuilds generated product/certificate/home fixes after sync or local edits.

`scripts/contact-form.js`:

- Looks for `[data-contact-enquiry-form]`.
- Prevents Webflow's default form behavior.
- Submits via `fetch` to the form's `action`.
- Shows/hides Webflow success/error blocks.
- Uses guards around the submit button mutation observer to avoid an infinite loop/freezing bug.

Do not remove the guarded `unlockSubmit()` logic unless replacing the whole form handling intentionally.

## Tooling Details

`scripts/lib/site.mjs` discovers pages and checks mirrored asset references. It skips `cdn.prod.website-files.com`, `node_modules`, `.git`, `scripts`, and `.claude`.

`scripts/health-check.mjs`:

- Finds all pages.
- Checks each page's local assets, including mirrored Webflow assets and local root assets such as `/styles/devasya-codex.css`, `/scripts/nav-fallback.js`, and `/documents/chemical-composition.pdf`.
- Optionally checks live Webflow staging routes with `--live`.
- Exits non-zero on failures.

`scripts/sync-site.mjs`:

- Pulls routes from `https://devasyagroup.webflow.io`.
- Downloads missing CDN assets.
- Rewrites `https://cdn.prod.website-files.com/` references to `/cdn.prod.website-files.com/`.
- Rewrites the shared CSS and preserves the Webflow badge-hiding override.
- The explicit `ROUTES` list excludes `/`; home is included as the existing local `index.html` for post-processing, not freshly downloaded.

`scripts/normalize-shared.mjs`:

- Removes Webflow export comments and generator meta tags from HTML.
- Removes the dead visible `Log in` link from duplicated nav blocks.
- Converts internal production-domain anchor links back to local root-relative links.
- Standardizes the primary call/WhatsApp number to `+91 9924788225`.
- Fixes contact-page phone/email card links and the old misspelled sales Gmail.
- Replaces every repeated footer with one clean shared footer.

`scripts/apply-client-changes.mjs`:

- Ensures `/styles/devasya-codex.css` is included on pages and regenerates the custom responsive navbar.
- Adds `download` to brochure PDF anchors.
- Removes old external `ChemicalComposition.pdf`, bright-bar `/specification/brightbar/...`, and PR typo `/public/chemidtry.pdf` links from product pages.
- Injects generated spec tables from `data/product-specs.json`.
- Consolidates legacy product-page specification bullets into the generated spec table and removes the duplicated old rich-text spec blocks.

## Editing Guidance

- Use `rg` first. Webflow exports repeat nav/footer/contact blocks across every page.
- Keep URLs root-relative for local pages/assets unless the link is intentionally external.
- Prefer targeted edits to repeated blocks. After changing shared header/footer content, verify all 22 pages.
- Preserve Webflow classes/attributes unless you know the interaction does not depend on them.
- Be careful with the footer newsletter form: it is Webflow markup and does not have the same custom handling as the contact enquiry form.
- For new local assets, place them in a sensible local folder or the mirror, then run `npm run check`.
- When changing product links, remember the typo route `/bars/sqaures-bar`.
- After edits, run `npm run check`. For visual/client-facing changes, also run `npm run serve` and inspect `/__dev` plus representative routes.
- After `npm run sync`, run `npm run normalize` before reviewing pages.
